# CI is green — first success since 2026-08-13

## What was wrong

CI had failed on **25 consecutive runs**. The failure was at the **Lint** step
(`ruff format --check`), which is step 4 of 9 — so every step after it was
skipped for six days:

- the test suite
- the corpus determinism check
- the eval harness
- **`eval-vertex-off`**, the job the README calls
  *"THE GUARANTEE, as a required check rather than a demo moment"*

The zero-model guarantee this project's thesis rests on had not executed in CI
since 2026-08-13. It held — it passes locally — but the mechanism that was
supposed to keep it from rotting had itself rotted.

**Root cause:** `pyproject.toml` pinned `ruff>=0.7.0` with no ceiling. CI
installs the newest ruff on every run; ruff 0.16.3's formatter legitimately
disagreed with formatting written against an older release. A formatter is a
moving target, and a moving target is not a gate — it is a coin flip.

## What fixing it exposed

Repairing the lint gate surfaced **two further failures that had been invisible
behind it**:

1. **Model-string guards.** `tests/test_config_singleton.py` and
   `tests/test_countersign_boundary.py` enforce that model strings appear only
   in `lib/config.py`. A new test hardcoded one, and a committed evidence log
   recorded one. Both guards scan *tracked* files, so neither was visible in a
   local run with those files unstaged. **Lesson recorded: a local run is only
   equivalent to CI after `git add`.**

2. **`verify-live refuses to run without credentials`.** This step required
   `docs/LIVE-VERIFICATION.md` to contain the literal string `NOT YET RUN` —
   a proxy for "the script wrote nothing". That stopped being true on
   2026-08-13 when commit `ba46aaa` legitimately replaced the placeholder with
   real measured results from a credentialed run. **Every push had failed this
   step for a week**, hidden because the job died at Lint first.

Neither was caused by this pass. Both were found by it.

## Fixes

| Problem | Fix | Weakened? |
| --- | --- | --- |
| Unpinned formatter | `ruff==0.16.3`, pinned exactly | No — stricter |
| Hardcoded model string in a test | import `MODEL_DEEP` from `lib.config` | No — the test now tracks the real config instead of a stale literal |
| Model string in an evidence log | extend the existing prose exemption to recorded output under `evidence/` (`.log`/`.json`/`.txt` only, never source) | No — a source file under `evidence/` is still caught |
| `verify-live` placeholder grep | hash the file before and after the uncredentialed run | No — **stronger**: the grep would have passed a run that appended garbage while leaving the placeholder line intact |
